# Voice Era Tech LLC — Enterprise Website

A world-class, premium, highly interactive corporate website for **Voice Era Tech LLC**, a technology company specializing in **dialer systems, call-center technology, AI voice agents, cloud infrastructure and digital solutions**.

## 🚀 Tech Stack

| Category | Technology |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS + Vanilla CSS Design System |
| Animation | Framer Motion + GSAP |
| Smooth Scroll | Lenis |
| Icons | Lucide React |
| Theming | next-themes |

## ✨ Features

### Homepage
- **Animated Preloader** — Canvas-based circular dialer assembly with signal travel
- **Custom Cursor** — Context-aware cursor with EXPLORE/CONNECT labels (desktop)
- **Hero Section** — Cinematic headline with interactive 3D-tilting dialer card
- **Network Graph** — Clickable infrastructure topology with animated data packets
- **Dialer Products** — Tabbed showcase for 6 dialer types with key capabilities
- **How It Works** — Alternating 7-step workflow timeline
- **AI Section** — Neural network canvas with voice AI flow visualization
- **Services Matrix** — Click-to-expand 6-category service grid
- **Stack Builder** — Interactive technology configurator
- **Industry Selector** — 10-industry solution panel
- **Analytics Dashboard** — Realistic SaaS demo dashboard (labeled as demo)
- **"The Call" Signature** — Animated signal traversal through the infrastructure

### Navigation
- **Mega Menu** — Animated 5-column dropdowns for all service areas
- **Mobile Menu** — Full-screen overlay with all navigation links

### Design System
- Midnight Telecom color palette (deep navy, electric blue, cyan, violet)
- Plus Jakarta Sans + JetBrains Mono typography
- Dark-first with CSS custom property theming
- Smooth micro-animations throughout
